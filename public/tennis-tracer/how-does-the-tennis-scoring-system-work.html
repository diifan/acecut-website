How tennis scoring works: points, games and sets

In a standard advantage game, point scores progress through love, 15, 30 and 40. At 40–40 the score is deuce. A player must then win two consecutive points to take the game: advantage, followed by game. Losing the advantage point returns the game to deuce.

Keep three levels separate

Points make up a game; games make up a set; sets make up a match. Write each level separately when taking notes so a point score cannot be mistaken for a game count.

Confirm the format before starting

No-ad games, tie-break sets and match tie-breaks have different procedures. Check the event format before play; this explanation covers standard advantage games rather than every competition format.

Use this checklist

  • Write down the agreed match format.
  • Call the server’s score first.
  • Record the game count separately from the point score.
